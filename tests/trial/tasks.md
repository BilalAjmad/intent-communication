# Trial Task Cards

Each persona does 2 tasks, order balanced across arms.

## Task T1 — First prototype
Build the app described by the persona's goal on the listed screens, with their
style mood, palette, theme, density, corner, tone, data type, states, nav type
and primary action. The prototype must be usable on the stated device.

## Task T2 — Add a feature
Add a "Notifications" screen with a list of recent activity, an unread badge,
and a "Mark all read" action. Keep the existing visual language.

## Task T3 — Revise after feedback
The persona sends Studio feedback: "the primary action is too small and the empty
state has no guidance". Apply the feedback and re-export.
